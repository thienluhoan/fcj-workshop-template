**Trong trang này**, tôi tổng hợp lại toàn bộ nhật ký công việc (**Worklog**) trong suốt quá trình tham gia chương trình thực tập **First Cloud AI Journey (FCAJ)**.

Chương trình được tôi hoàn thành trong vòng **11 tuần** (từ **14/09/2026** đến **27/11/2026**), theo sát lộ trình học tập và thực hành trên hệ thống tài liệu **Cloud Journey (AWS Study Group)**. Trong suốt 11 tuần, tôi đã đi từ những bước nền tảng như thiết lập tài khoản, quản trị ngân sách và làm quen các dịch vụ cốt lõi, đến các chủ đề chuyên sâu về giám sát, bảo mật, mạng đa VPC, Container, CI/CD, lưu trữ lai, Data Lake, tối ưu chi phí (FinOps), hiện đại hóa ứng dụng sang Microservices, kiến trúc Serverless và tích hợp các dịch vụ AWS AI. Sau mỗi bài lab, toàn bộ tài nguyên thử nghiệm đều được thu dọn đầy đủ để tối ưu chi phí.

Nội dung chi tiết từng tuần như sau:

**Tuần 1:** [Làm quen môi trường thực tập, cộng đồng FCAJ, khởi tạo tài khoản AWS, nhận $100 AWS Credits và thiết lập AWS Budgets](1.1-week1/)

**Tuần 2:** [Tổng quan lộ trình, thực hành VPC, EC2, Security Group, tự động hóa với CloudWatch & Lambda (thông báo Slack) và tham gia Kickoff FCAJ Builderathon 2026](1.2-week2/)

**Tuần 3:** [Tham dự AWS Cloud and AI Day, triển khai EC2 Linux với IAM Role, cài đặt Grafana và tích hợp Amazon CloudWatch giám sát hệ thống](1.3-week3/)

**Tuần 4:** [Quản lý tài nguyên bằng Resource Tags & Resource Groups, phân quyền IAM ABAC, quản lý bản vá và kết nối bảo mật với AWS SSM Session Manager](1.4-week4/)

**Tuần 5:** [Triển khai hạ tầng bằng mã với AWS CloudFormation, cấu hình AWS IAM Identity Center (SSO), Permission Boundaries, Role Assumption Conditions và AWS Security Hub](1.5-week5/)

**Tuần 6:** [Bảo mật ứng dụng với AWS WAF, quản lý khóa AWS KMS, sao lưu với AWS Backup và kết nối mạng liên VPC bằng VPC Peering & AWS Transit Gateway](1.6-week6/)

**Tuần 7:** [Thực hành chuyên sâu AWS Backup, VPC Peering, Transit Gateway, đóng gói ứng dụng bằng Docker và triển khai trên Amazon ECS & ECR](1.7-week7/)

**Tuần 8:** [Xây dựng quy trình CI/CD tự động với AWS CodePipeline, lưu trữ lai AWS Storage Gateway, Amazon FSx for Windows và xây dựng Data Lake với S3, AWS Glue & Athena](1.8-week8/)

**Tuần 9:** [Kiến trúc NoSQL nâng cao với Amazon DynamoDB và tối ưu hóa chi phí AWS (FinOps): Savings Plans/RI, EC2 Right-sizing, trực quan hóa & phân tích CUR bằng Glue và Athena](1.9-week9/)

**Tuần 10:** [Hiện đại hóa ứng dụng: di chuyển Monolith lên AWS, Auto-release CI/CD, tách Microservices, tái cấu trúc dữ liệu/workflow với Step Functions và giao tiếp hướng sự kiện (SQS, SNS, EventBridge)](1.10-week10/)

**Tuần 11:** [Xây dựng & xác thực SPA với S3, CloudFront, Cognito; trải nghiệm AWS AI Services; điều phối AWS Step Functions và hoàn thiện ứng dụng Serverless Full-stack với API Gateway, Lambda, S3 & DynamoDB](1.11-week11/)
