This worklog records my 12-week internship (from 09/14/2026; recorded up to the submission date 11/30/2026) in the **First Cloud Journey (FCJ)** program. I work as the **Cloud Architecture & DevSecOps Lead (Member 3)** in a 4-person team building **SecureTable – a secure restaurant management system on AWS**.

**How I kept this worklog:** every day I noted what I did or was working on, the detailed content, the reference material (links to the exact lab or document page) and the lessons learned; at the end of each week I summarised them into a weekly page following the template: weekly objectives, a day-by-day task table and achievements.

**The journey has three stages:**

- **Weeks 1–5:** AWS fundamentals through FCJ workshops (account, cost, IAM, VPC, EC2, S3, RDS, DynamoDB, Lambda, API Gateway, Cognito, KMS, WAF…) alongside real-world surveys to choose the capstone topic.
- **Weeks 6–8:** infrastructure with Terraform, moving the architecture from 3-tier to 100% Serverless, a security review and a DevSecOps pipeline in CI (gitleaks, Checkov, Trivy, Bandit, pytest, terraform test).
- **Weeks 9–12:** strengthening CI/CD & DevSecOps, writing technical blog posts, then wiring Lambda – API Gateway – Cognito – CloudFront, monitoring, load testing, WAF pentesting and a disaster-recovery drill.

**Weekly content:**

**Week 1:** Getting started with AWS: account, cost, IAM and VPC networking

**Week 2:** Finishing the VPC lab, first IaC with CloudFormation; EC2, IAM Role, AWS CLI and S3

**Week 3:** Databases & messaging on AWS; finding the project topic through real surveys

**Week 4:** Serverless basics (Lambda, API Gateway, Cognito) and settling the project direction

**Week 5:** Security on AWS: advanced IAM, KMS, WAF, Secrets Manager and S3 security

**Week 6:** Terraform and the first infrastructure version (3-tier Smart Kitchen architecture)

**Week 7:** Moving to a 100% Serverless architecture – kicking off SecureTable

**Week 8:** Completing the infrastructure foundation, security review and DevSecOps in CI

**Week 9:** Strengthening CI/CD & DevSecOps: GitHub Actions, scanners, OIDC and IaC testing

**Week 10:** Advanced Git, technical blogging, threat modeling and a Cloud/DevSecOps learning roadmap

**Week 11:** Wiring the system (Lambda, API Gateway, CloudFront) and finishing the internship report

**Week 12:** Final review and Workshop submission (deadline 11/30/2026)
