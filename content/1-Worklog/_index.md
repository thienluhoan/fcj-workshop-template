**On this page**, I summarize my entire worklog throughout the **First Cloud AI Journey (FCAJ)** internship program.

I completed the program over **11 weeks** (from **September 14, 2026** to **November 27, 2026**), closely following the learning path and hands-on labs on **Cloud Journey (AWS Study Group)**. Across these 11 weeks, I progressed from foundational topics—such as account setup, budget governance, and core AWS services—to advanced areas including monitoring, security, multi-VPC networking, containers, CI/CD, hybrid storage, Data Lake, cloud cost optimization (FinOps), application modernization to Microservices, Serverless architecture, and AWS AI services. After every lab, all test resources were properly cleaned up to prevent unnecessary costs.

Below is the weekly summary:

**Week 1:** [Internship onboarding, connecting with the FCAJ community, creating an AWS account, earning $100 in AWS Credits, and configuring AWS Budgets](1.1-week1/)

**Week 2:** [Learning path overview, hands-on with VPC, EC2, and Security Groups, automating EC2 scheduling with CloudWatch & Lambda (Slack notifications), and attending FCAJ Builderathon 2026 Kickoff](1.2-week2/)

**Week 3:** [Attending AWS Cloud and AI Day, provisioning EC2 Linux with IAM Roles, installing Grafana, and integrating Amazon CloudWatch as a Data Source for system monitoring](1.3-week3/)

**Week 4:** [Managing resources with Resource Tags & Resource Groups, IAM ABAC authorization, Windows patch management, and secure access via AWS SSM Session Manager (S3 Logging & Port Forwarding)](1.4-week4/)

**Week 5:** [Infrastructure as Code with AWS CloudFormation, configuring AWS IAM Identity Center (SSO), applying IAM Permission Boundaries, Role Assumption Conditions, and compliance checks with AWS Security Hub](1.5-week5/)

**Week 6:** [Securing web applications with AWS WAF, managing encryption keys with AWS KMS, automating backups with AWS Backup, and connecting VPCs via VPC Peering & AWS Transit Gateway](1.6-week6/)

**Week 7:** [Deep-dive practice with AWS Backup, VPC Peering, and Transit Gateway; containerizing applications with Docker and deploying to Amazon ECS & ECR](1.7-week7/)

**Week 8:** [Building automated CI/CD pipelines with AWS CodePipeline, hybrid cloud storage with AWS Storage Gateway, Amazon FSx for Windows File Server, and building a Data Lake with S3, AWS Glue & Amazon Athena](1.8-week8/)

**Week 9:** [Advanced NoSQL architecture with Amazon DynamoDB and AWS cost optimization (FinOps): Savings Plans/RI, EC2 Right-sizing, cost visualization, and CUR analysis using AWS Glue & Athena](1.9-week9/)

**Week 10:** [Application modernization: migrating a Monolith to AWS, Auto-release CI/CD, extracting Microservices, data & workflow restructuring with AWS Step Functions, and event-driven messaging (SQS, SNS, EventBridge)](1.10-week10/)

**Week 11:** [Building & authenticating a Single Page Application (SPA) with S3, CloudFront, and Cognito; exploring AWS AI Services; orchestrating workflows with AWS Step Functions; and completing a full-stack Serverless app with API Gateway, Lambda, S3 & DynamoDB](1.11-week11/)
